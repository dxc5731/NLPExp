## 三、实现严格实体级评价指标

这是本阶段最核心的功能。

实现独立、可测试的实体提取与评分函数。

从每个句子的 BIO 标签序列恢复实体，实体由以下信息唯一确定：

- 原始对话 ID
- 原始句子 ID
- 实体类型
- 起始字符位置
- 结束字符位置（建议使用左闭右开区间，并明确写入文档）

只有预测实体与金标准的**类型、起点和终点全部一致**才算 TP。

不允许部分匹配、模糊匹配、文本相似度匹配，也不使用人为加权。

按严格匹配统计：

- TP：正确预测的实体数量。
- FP：预测中存在但金标准中不存在的实体数量。
- FN：金标准中存在但预测中未正确识别的实体数量。

计算：

- Precision = TP / (TP + FP)
- Recall = TP / (TP + FN)
- F1 = 2PR / (P + R)

明确规定零分母处理方式，保证没有实体、没有预测等情况不会报错或产生 NaN，并在输出中保留原始 TP/FP/FN 计数。

分别输出：

1. 五类实体各自的 TP、FP、FN、Precision、Recall、F1。
2. 全部实体汇总后的 Micro-Precision、Micro-Recall、Micro-F1。
3. 金标准实体总数和预测实体总数。

**整体实体级 Micro-F1 是我们的主指标。**

注意：

- 在所有句子上汇总 TP/FP/FN 后再计算 micro 指标。
- 不能先计算每句话的 F1 再取平均。
- 不同句子里相同的实体位置不能互相匹配。
- 相邻同类型实体需要正确区分。
- 第一阶段已经要求严格 BIO 合法，因此评分时不应悄悄修复非法标签序列。

评分口径尽可能与固定版本的作者 Task1 实体级 overall F1 保持一致。

- TP：严格匹配成功的实体。
- FP：预测存在但金标准不存在的实体。
- FN：金标准存在但预测未正确识别的实体。

每条记录至少包含：

- run_id、方法名称、数据划分。
- 原始 dialogue_id、sentence_id。
- 错误记录 ID。
- 记录类别（TP/FP/FN）。
- 实体类型。
- 实体 start/end，左闭右开。
- 实体所在的字符位置。
- 可追溯的金标准及预测文件标识。

原始医疗句子和实体文本属于可选的本地分析材料，不要默认写进通用日志、公开比较表或课程提交 ZIP。

提供显式的本地分析导出选项，允许我后续人工查看必要的句子上下文、金标准实体文本及预测实体文本；默认使用不含完整医疗原文的结构化错误记录。文档说明本地详细材料的隐私与提交边界。

### 2. 自动发现常见差异

在基础 TP/FP/FN 之外，可以自动识别以下**候选错误现象**：

- 类型不一致：实体跨度相同，但类别不同。
- 边界不一致：实体类型相同，但跨度不同且存在重叠。
- 疑似漏检：金标准实体未被匹配。
- 疑似误检：预测实体未被匹配。

注意区分两个层次：

**严格评分**始终依据 TP/FP/FN，不允许部分正确抵消 FP 或 FN。

**错误现象分类**只是辅助人工查看差异，不能改变原始计数。

例如一个边界错误同时产生一个 FP 和一个 FN，不能因为将两者关联为同一现象就从评分中删除。

如果实现 FP/FN 候选关联，需要确定性、一对一关联，避免同一实体被重复配对；不确定的情况保留未关联状态，不强行分类。

不要自动把“类型不一致”“边界不一致”等现象推断成模型失败的根本原因。真正的错误归因，例如训练数据问题、长文本截断、上下文不足、过拟合等，需要团队根据真实证据自行分析。

### 3. 错误明细输出

建议支持：

- `entity_errors.csv`：基础 FP/FN 明细。
- `error_candidates.csv`：候选边界／类型差异及其关联信息。
- `error_summary.json`：按实体类别、错误现象统计的数量。

CSV 使用 UTF-8，保证中文、Excel 和 Python 可正确处理，必要时提供 UTF-8 BOM 兼容方案；同时注意 CSV 公式注入风险，不将任意原文直接作为可执行公式单元格。

优先只导出发生错误的句子，不生成冗余的大型完整预测副本。

输出必须可追溯、可重复计算，并且不能覆盖历史运行结果。

### 4. 必须完成的一致性校验

错误明细中的统计必须与已经计算的 `evaluation.json` 完全对应。

逐类验证：

- Gold 实体数 = TP + FN。
- Predicted 实体数 = TP + FP。
- 错误明细 FP 数量 = 评分结果 FP。
- 错误明细 FN 数量 = 评分结果 FN。
- 各类别及整体统计均一致。

出现不一致必须报错，不允许生成表面成功的错误报告。

## 五、任务三：补充运行信息与复现证据核查

已有 `docs/预测结果交接规范.md` 规定了 `run_info.json` 的字段。
