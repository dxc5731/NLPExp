# 评估模块首次入库说明

## 范围与状态

本地评估工程于 2026-10-16 至 2026-10-17 完成分阶段开发与人工验证，2026-10-18 按用户确认的方案整理到 `evaluation` 分支的 `evaluation/` 目录。Git 提交采用实际入库日期，历史日志保留原日期；这些提交不表示全部开发发生在首次入库当天。

本模块负责 IMCS-V2-NER / Task1 的校验、严格实体和逐字符评分、错误明细、运行信息核查、多方法比较与批量接入。当前没有真实 BERT、CRF 或规则模型预测／成绩；人工样例和通过的程序测试仅证明已验证的工程行为。正式实验设置、真实模型接入和分析仍待团队完成。

## 文件选择与来源

- 源码、现有测试、人工示例、配置模板和交接文档保留既有结构；八个评估实现文件保持原字节和算法。
- 第一、二阶段日志及第三阶段最终验收目录按原字节保留；重复中间批次不发布。历史 JSON 中的本机绝对路径是原执行位置，文件迁移不使旧路径自动可用，也不把旧结果改写为新运行。
- 新目录中的复跑使用新的独立输出，入口与结果见[重新检出验证](../logs/repository_validation/README.md)。既有原始输入和历史日志不覆盖。
- 数据、权重、环境、真实预测、本地医疗原文分析、密钥、旧榜单 JSON 与截图不进入首次发布。只保留支持当前文档的必要公开配置快照，并明确日期与限制。

迁入记录、原始哈希和发布文件哈希见 [publication_manifest.json](publication_manifest.json)。[历史资料来源](资料来源.json)是原工作目录的来源记录，部分列项属于未发布的历史存档；发布范围以本次清单为准。

## 可移植性调整

命令均以仓库 `evaluation/` 为工作目录；真实数据默认位置改为本模块 `data/IMCS-V2-NER.zip`，本地清单从模板复制后按实际交付填写。路径规则保持不变：清单内相对路径以清单所在目录为基准，run_info 中引用以 run_info 所在目录为基准。

上游作者参考没有声明许可证，保留固定版本 URL 和 SHA-256，并提供一次性下载／离线准备工具；源码不随仓库分发。CBLUE 格式检查参考保留上游来源和 Apache-2.0 许可。仓库未替团队原创代码选择新的开源许可证。

`.gitattributes` 关闭评估材料的自动行尾转换，避免不同检出环境改变哈希。原工作目录保留；目录迁移后评估原有真实记录应按交接规范重新接入，不改写旧报告。
