全部句子、对话标识和预测由人工构造，不含真实医疗对话或真实数据 ID。
`甲乙…` 与 Unicode 字符串用来检验五类标签、标点、空格及非 BMP 字符位置。
这些标签仅用于算法验算，不表示真实语义标注，也不是模型成绩。

scorer_validation 的手算结果：TP=2、FP=2、FN=3，P=0.5、R=0.4、F1=4/9；字符正确17/22。
