## 检查和源码预览包

在仓库根目录执行，Python 标准库，无模型调用：

```powershell
python -B -X utf8 scripts/package_delivery.py --check
python -B -X utf8 scripts/package_delivery.py --source-only --output ../NLPExp_源码交付预览.zip
```

脚本只打包 `source_files.json` 中经过审查的文件，不扫描加入工作目录里的私有数据、运行记录、环境或未跟踪文件。拒绝覆盖已有 ZIP。逐文件核验 SHA（允许 Git 换行转换）、检查嵌套交接包成员和 CRC，超 50,000,000 字节即拒绝。GitHub 下载的源码 ZIP 没有 `.git` 也能使用。

## 证据阅读规则
