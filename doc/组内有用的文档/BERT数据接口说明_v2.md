# BERT 数据接口说明 v2（给成员 B）

> v1 的四个问题已全部修复。这一版的原则只有一句：**对不上就报错，绝不猜**。

## 0. 相对 v1 改了什么

| 问题 | v1 的做法 | v2 的做法 |
|---|---|---|
| 词片跨实体边界（如 `838` 覆盖 `I/B/I`） | 取首字符标签，等于伪造 | 先判断「这个标签摊回去能不能逐字还原」；不能就填 **-100 不参与训练**，并记进 `ambiguous` |
| 非法 BIO | 还原时自动把 `I` 改成 `B` | 对齐路径**不修**；只在导出预测时显式修，并返回「修了几处」 |
| 未覆盖的字符 | 自动补 `O` | 返回 `None`；导出时遇到 `None` 直接报错 |
| 长句 | 开着截断，静默丢尾巴 | **关闭截断**，超过上限直接抛异常，带对话 ID 和句子 ID |

判断「能不能无损」用的是还原规则本身，不是「字符标签是否相同」：
`37` 覆盖 `B-Symptom + I-Symptom`，摊回去正好还是 `B + I`，**不算歧义**；
`838` 覆盖 `I + B + I`，任何单一标签都还原不出中间的 `B`，才算歧义。

## 2. 训练集里那 8 个歧义词片（全列出来）

| # | 对话 / 句子 | 原文 | 词片 | 覆盖位置 | 字符标签 |
|---|---|---|---|---|---|
| 1 | 10034734 / 2 | 宝宝37.838属于低热 | `838` | 5–8 | I, B, I（Symptom） |
| 2 | 10098865 / 21 | 3637.4正常的 | `363` | 0–3 | O, O, B（Symptom） |
| 3 | 10193361 / 25 | 37.338.5可以贴降温贴… | `338` | 3–6 | I, B, I（Symptom） |
| 4 | 10206772 / 25 | 37.338.5度可以贴降温贴… | `338` | 3–6 | I, B, I（Symptom） |
| 5 | 10491432 / 7 | 宝宝8个月了！…37.538度！ | `53` | 19–21 | I, B（Symptom） |
| 6 | 10506585 / 10 | 体温的确不是很高，…就38度多一点点。 | `38` | 20–22 | O, B（Symptom） |
| 7 | 10515756 / 10 | 一直37.638,昨晚退了,今天又来 | `63` | 5–7 | I, B（Symptom） |
| 8 | 10731191 / 31 | 胆红素303，这个数字是相当高的呀 | `303` | 3–6 | I（检查）, O, O |

原因都是同一个：金标在数字串中间切了一刀（把「37.8」和「38」标成两个实体），而 WordPiece 把中间几个数字合成了一个词片。**这是分词粒度比字符粗造成的固有损失，不是标注错误，也不是代码 bug。**
完整明细（含原文、起止位置）在 `code/artifacts/alignment_report_train.json` 的 `ambiguous_detail` 里。

## 3. 接口

batch 的键没变，兼容 v1：

| 键 | 形状 | 说明 |
|---|---|---|
| `input_ids` | [B, L] | 词片编号 |
| `attention_mask` | [B, L] | 1=真实词片 |
| `labels` | [B, L] | **-100** 现在有三种含义：特殊符号、补位、无法无损表示的词片 |
| `offsets` | [B, L, 2] | 词片 → 原文 [起, 止) |
| `dialogue_id` / `sentence_id` / `text` | list[str] | 原始 ID 和原文 |

`-100` 交叉熵会自动忽略，训练代码**不用改**。

新增（不在 batch 里，挂在 Dataset 上）：

```python
ds = NerDataset(examples, tokenizer)
ds.char_labels[i]     # 第 i 句的字符级金标，原样，len == len(原文)
ds.ambiguous          # [(对话ID, 句子ID, {start, end, text, tags}), ...]
ds.report()           # 汇总：几个歧义词片、涉及几句
```

## 4. 解码

```python
from src.align import restore_char_labels, to_legal_bio

tags = restore_char_labels(token_label_ids, offsets, len(text))  # 元素可能是 None
legal, n_repaired = to_legal_bio(tags)                            # 显式修复并计数
```

- 对齐校验时**不要**调 `to_legal_bio`，要的就是原始映射。
- 导出预测时必须调，**并且把 `n_repaired` 记进日志**——修了多少处是实验记录的一部分。
- 预测场景下 `restore_char_labels` 不会返回 `None`，因为模型对每个真实词片都给了标签；`None` 只出现在金标一侧。

## 5. 三条不许做的事（不变）

1. **不许用 dev 训练或调参。** dev 只用于最后交作业。
2. **不许改句子原文。** 不删空格、不归一化、不拼 speaker。标签数必须等于 `len(sentence)`。
3. **不许改 ID。** `"01"` 和 `"1"` 是两个不同的句子。
